# คู่มือการใช้งานอย่างละเอียด: TradingView DZ/SZ Discord Alert Extension

ส่วนขยาย **Google Chrome Extension (Manifest V3)** รูปแบบ **Side Panel** สำหรับตรวจจับสัญญาณ **Demand Zone (DZ)** และ **Supply Zone (SZ)** บนหน้ากราฟ TradingView เมื่อแท่งเทียนปิด (Candle Close) และส่งการแจ้งเตือนไปยัง **Discord Webhook** แบบอัตโนมัติ พร้อมภาพแคปหน้าจอกราฟและทำงานในเบื้องหลังได้ตลอดเวลา

## 1. คุณสมบัติเด่นของโปรแกรม

- 🖤 **ดีไซน์โทนสีดำ (Modern Dark Theme)**: ออกแบบสไตล์ Dark Glassmorphism สบายตา ใช้งานง่าย
- ⚡ **ทำงานเบื้องหลังตลอดเวลา (True Background)**: บอทยังคงเฝ้ากราฟและส่งแจ้งเตือนแม้จะปิดแถบ Side Panel หรือย่อหน้าต่างเบราว์เซอร์
- 🪟 **รองรับ Windows 7 (Chrome 109+)**: รองรับทั้ง Side Panel บน Chrome รุ่นใหม่ และ Action Popup / Pop-out Window บน Windows 7
- ⏱️ **ตรวจจับเมื่อปิดแท่งเทียน (Candle Close Accuracy)**: ติดตามตัวนับเวลาถอยหลัง (Countdown) ของแท่งเทียนแบบวินาทีต่อวินาที
- 📸 **แคปภาพกราฟอัตโนมัติ (Chart Snapshot)**: ถ่ายภาพหน้าจอกราฟขณะเกิดสัญญาณแนบส่งเข้า Discord ทันที
- 🟢 **แยกสีชัดเจน**: สัญญาณ **Demand Zone (DZ)** สีเขียวมรกต และ **Supply Zone (SZ)** สีแดงทับทิม

## 2. วิธีสร้าง Discord Webhook URL (ทีละขั้นตอน)

ก่อนเริ่มใช้งาน Extension คุณต้องมี Webhook URL จากห้องแชท Discord ที่ต้องการให้บอทส่งข้อความแจ้งเตือน:

1. เปิดโปรแกรม **Discord** และเข้าไปใน Server ที่คุณเป็นผู้ดูแล (Admin)
2. ไปที่ห้องข้อความ (Text Channel) ที่ต้องการรับการแจ้งเตือน -> คลิกที่ **ไอคอนรูปฟันเฟือง (Edit Channel)** ข้างชื่อห้อง
3. เมนูด้านซ้าย เลือกหัวข้อ **Integrations (การผสานรวม)**
4. คลิกที่ปุ่ม **Webhooks** -> คลิก **New Webhook (สร้างเว็บฮุกใหม่)**
5. ตั้งชื่อบอทตามต้องการ เช่น `TV DZ/SZ Alert` และเลือกห้องข้อความ
6. คลิกปุ่ม **Copy Webhook URL (คัดลอก URL เว็บฮุก)**
7. นำ URL ที่ได้ไปวางในช่อง `Discord Webhook URL` ในหน้าต่าง Extension

## 3. วิธีติดตั้ง Extension ลงใน Google Chrome

1. เปิดเบราว์เซอร์ **Google Chrome**
2. พิมพ์ `chrome://extensions` ลงในช่องที่อยู่ URL แล้วกด **Enter**
3. ที่มุมบนขวา ให้เปิดสวิตช์ **Developer mode (โหมดนักพัฒนา)** ให้เป็นสีฟ้า
4. คลิกที่ปุ่ม **Load unpacked (โหลดส่วนขยายที่คลายการบีบอัดแล้ว)** ที่มุมบนซ้าย
5. หน้าต่างเลือกโฟลเดอร์จะเปิดขึ้นมา ให้เลือกไปที่โฟลเดอร์:
   ```
   d:\Github\Tradingview\Extension\TV1
   ```
   แล้วคลิก **Select Folder (เลือกโฟลเดอร์)**
6. ส่วนขยาย **TradingView DZ/SZ Discord Alert** จะปรากฏในรายการ
7. แนะนำให้คลิกที่ **ไอคอนรูปชิ้นส่วนจิ๊กซอว์ 🧩** บนแถบเครื่องมือมุมบนขวาของ Chrome แล้วกด **ปักหมุด (Pin)** เพื่อให้ไอคอนแสดงตลอดเวลา

## 4. คำอธิบายหน้าต่างควบคุมและปุ่มการทำงาน

เมื่อเปิดหน้าต่าง Extension ขึ้นมา จะพบกับส่วนประกอบหลักดังนี้:

### 4.1 แถบควบคุมหลัก (Top Control Bar)
- ▶ **ปุ่ม Play (สีเขียว)**: สั่งให้ระบบเริ่มทำงานและเฝ้าดูกราฟในเบื้องหลัง ไฟสถานะจะเปลี่ยนเป็น `RUNNING` สีเขียวกะพริบ
- ⏹ **ปุ่ม Stop (สีแดง)**: หยุดการทำงานของระบบ สถานะจะเปลี่ยนเป็น `STOPPED`
- ⚡ **ปุ่ม Test (สีม่วง)**: ทดสอบส่งข้อความแจ้งเตือนตัวอย่างพร้อมรูปถ่ายหน้าจอเข้า Discord ทันที เพื่อตรวจสอบว่า Webhook ใช้งานได้ปกติ
- 🪟 **ปุ่ม Pop-out Window (มุมบนขวา)**: แยกหน้าต่างแผงควบคุมออกมาเป็นหน้าต่างลอยอิสระ สะดวกมากเมื่อใช้หลายหน้าจอหรือใช้งานบน Windows 7

### 4.2 สถานะหน้ากราฟสด (Live TV Status)
- **Symbol**: แสดงคู่เหรียญ/หุ้นที่เปิดอยู่บน TradingView เช่น `BTCUSDT`, `XAUUSD`
- **Timeframe**: แสดง Timeframe ของหน้ากราฟ
- **Candle Close In**: ตัวนับเวลาถอยหลังก่อนแท่งเทียนปัจจุบันจะปิด (เช่น `02:45`)
- **Last Price**: ราคาล่าสุดของแท่งเทียน
- **สัญญาณล่าสุด**: แสดงสถานะ DZ หรือ SZ ล่าสุดที่ตรวจจับได้ พร้อมราคาและเวลา

### 4.3 การตั้งค่า (Settings)
- **Discord Webhook URL**: ช่องสำหรับใส่ Webhook URL (มีปุ่มไอคอนรูปตา 👁 เพื่อเปิด/ปิดการซ่อน URL)
- **Select TimeFrame**: เลือกระยะเวลาของแท่งเทียนที่ต้องการเฝ้าดู (`1M`, `5M`, `15M`, `30M`, `1H`, `4H`, `1D`)
- **ตรวจสอบเฉพาะเมื่อแท่งเทียนปิด**: แนะนำให้ติ๊กถูก เพื่อให้ระบบส่งสัญญาณเมื่อแท่งปิดสมบูรณ์แล้วเท่านั้น
- **แนบรูปถ่ายหน้าจอกราฟเข้า Discord**: ติ๊กถูกเพื่อให้ระบบแคปภาพหน้าจอกราฟ TradingView แนบส่งไปพร้อมกับการแจ้งเตือน
- **เปิดเสียงแจ้งเตือนในเบราว์เซอร์**: ติ๊กถูกเพื่อส่งเสียง Beep แจ้งเตือนเมื่อเกิดสัญญาณ
- **ปุ่ม บันทึก**: บันทึกการตั้งค่าทั้งหมด
- **ปุ่ม ยกเลิก**: คืนค่าการตั้งค่าเดิม

## 5. ขั้นตอนการเปิดใช้งานและจับสัญญาณบน TradingView

1. เปิดหน้ากราฟ **TradingView** (เช่น `https://www.tradingview.com/chart/...`)
2. ใส่ Indicator ที่บอกสัญญาณ Demand Zone / Supply Zone หรือ Smart Money Concepts ตามที่ท่านใช้งาน
3. เปิดหน้าต่าง **TV DZ/SZ Alert** (ผ่านแถบ Side Panel หรือคลิกที่ไอคอน Extension)
4. สังเกตการ์ด **สถานะหน้ากราฟ (Live TV Status)** จะขึ้นสถานะ `Online` พร้อมแสดงชื่อ Symbol และเวลานับถอยหลังของแท่งเทียน
5. วาง **Discord Webhook URL** แล้วกดปุ่ม **บันทึก**
6. กดปุ่ม **Test** หนึ่งครั้งเพื่อยืนยันว่าการส่งเข้า Discord ทำงานได้ถูกต้อง
7. กดปุ่ม **Play** เพื่อเริ่มการทำงาน
8. ระบบจะทำงานเฝ้ากราฟให้อัตโนมัติ เมื่อแท่งเทียนปิดและเกิดสัญญาณ DZ หรือ SZ บอทจะส่งการแจ้งเตือนพร้อมภาพถ่ายหน้าจอเข้า Discord ทันที

## 6. วิธีเปิดใช้งานบน Windows 7 (Chrome 109+)

สำหรับผู้ใช้ **Windows 7** ซึ่งรองรับเบราว์เซอร์ Google Chrome สูงสุดที่เวอร์ชัน **Chrome 109**:

1. Extension ตัวนี้ได้รับการออกแบบให้เข้ากันได้กับ Chrome 109 อย่างสมบูรณ์
2. เมื่อคลิกที่ไอคอน Extension แผงควบคุมจะเปิดขึ้นมาในรูปแบบ **Action Popup** ทันที
3. สามารถคลิกที่ **ไอคอนสี่เหลี่ยมมุมบนขวา (Pop-out Window 🪟)** เพื่อแยกหน้าต่างแผงควบคุมออกมาเป็นหน้าต่างเดี่ยวขนาดกะทัดรัด (Floating Window)
4. สามารถเปิดทิ้งไว้ข้างๆ จอ หรือย่อหน้าต่างเก็บไว้ได้ บอทจะยังคงทำงานในเบื้องหลังอย่างต่อเนื่อง

## 7. การทำงานในเบื้องหลัง (Background Monitoring)

Extension ตัวนี้ใช้สถาปัตยกรรม **Background Service Worker + Persistent Content Script**:
- เมื่อกด **Play** สถานะการทำงานจะถูกบันทึกไว้ใน `chrome.storage.local`
- ท่านสามารถ **ปิดแถบ Side Panel**, **สลับไปแท็บอื่น**, หรือ **เปิดโปรแกรมอื่นขึ้นมาบัง** ได้ โดยไม่ต้องเปิดแถบควบคุมค้างไว้
- ตราบใดที่แท็บกราฟ TradingView ยังเปิดอยู่บนเบราว์เซอร์ ระบบจะสแกนและส่งสัญญาณแจ้งเตือนตามรอบการปิดแท่งเทียนตลอดเวลา

## 8. การปรับแต่งคำค้นหาสัญญาณเพิ่มเติม (Keywords)

หากท่านใช้ Indicator ที่แสดงชื่อสัญญาณด้วยคำเฉพาะ สามารถปรับแต่งคำค้นหาได้ที่เมนู **"ตัวเลือกคำค้นหาสัญญาณเพิ่มเติม (Keywords)"**:

- **คำค้นหา Demand Zone (DZ)** ค่าเริ่มต้น:
  ```
  DZ, Demand, Buy Zone, Bullish OB
  ```
- **คำค้นหา Supply Zone (SZ)** ค่าเริ่มต้น:
  ```
  SZ, Supply, Sell Zone, Bearish OB
  ```
- สามารถพิมพ์คำค้นหาของ Indicator ที่ท่านใช้งานเพิ่มเข้าไปได้ โดยคั่นด้วยเครื่องหมายจุลภาค `,`

## 9. การแก้ไขปัญหาที่พบบ่อย (Troubleshooting & FAQ)

### Q1: กดปุ่ม Test แล้วข้อความไม่เข้า Discord
- **สาเหตุ**: Webhook URL ไม่ถูกต้อง หรือถูกลบออกจาก Server Discord
- **วิธีแก้**: ตรวจสอบ Webhook URL ว่าขึ้นต้นด้วย `https://discord.com/api/webhooks/...` หรือไม่ และลองคัดลอก URL ใหม่อีกครั้งจาก Discord

### Q2: แถบสถานะขึ้น Offline ไม่แสดงชื่อ Symbol
- **สาเหตุ**: ยังไม่ได้เปิดหน้ากราฟ TradingView หรือแท็บกราฟโหลดไม่สมบูรณ์
- **วิธีแก้**: เปิดหน้ากราฟ TradingView (`https://www.tradingview.com/chart/...`) และกดรีเฟรชหน้าเว็บ (F5) 1 ครั้ง

### Q3: รูปถ่ายหน้าจอกราฟไม่แนบส่งเข้า Discord
- **สาเหตุ**: แท็บ TradingView ถูกย่อขนาดลงจนเล็กเกินไป หรือเปิดตัวเลือกบล็อกภาพไว้
- **วิธีแก้**: ตรวจสอบว่าในหน้าต่าง Extension ติ๊กถูกที่ช่อง `แนบรูปถ่ายหน้าจอกราฟเข้า Discord` ไว้ และเปิดหน้าต่างเบราว์เซอร์ไว้ตามปกติ

### Q4: ต้องการให้แจ้งเตือนเสียงดังขึ้นในคอมพิวเตอร์
- **วิธีแก้**: ตรวจสอบว่าได้ติ๊กถูกที่ช่อง `เปิดเสียงแจ้งเตือนในเบราว์เซอร์ (Sound Alert)` และไม่ได้ปิดเสียง (Mute) แท็บเบราว์เซอร์ไว้
